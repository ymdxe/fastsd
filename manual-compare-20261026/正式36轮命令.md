# 正式36轮逐轮命令

仅在诊断、三方法parity正确性检查与60秒试测通过后执行。每轮等模型就绪，再在node1/node3分别启动客户端；完成后在GPU原服务终端Ctrl+C，再执行下一轮。保持相同GPU和隧道。

## 1. low_rep1 / ar

```bash
# gpunode2
bash /home/hdd3/zhangh/workspace/fastsd/manual-compare-20261026/launch.sh server ar low_rep1 low_rep1_ar

# node1 和 node3 各自执行（等 model_ready=true）
bash /home/zhangh/workspace/fastsd/manual-compare-20261026/launch.sh clients low_rep1_ar

# 完成后，GPU 另一终端查看
bash /home/hdd3/zhangh/workspace/fastsd/manual-compare-20261026/launch.sh summary low_rep1_ar
```
